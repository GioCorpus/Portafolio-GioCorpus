# Giovanny Portfolio

A dark, research-oriented personal portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Requirements

- Node.js 20+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Customize

Main content:
- `src/data.ts` — projects, skills and timeline
- `src/App.tsx` — layout and sections
- `src/index.css` — global visual system
- `index.html` — SEO title and description

Replace:
- `hello@example.com`
- project descriptions
- project URLs
- timeline
- skill lists
- CV link if added
